# **App Name**: RhythmicPulse

## Core Features:

- Tempo Control: Display a tempo control (slider or numeric input) to adjust beats per minute (BPM).
- Beat Generation: Generate audible clicks or visual flashes at the specified tempo.
- Start/Stop Control: Provide a start/stop button to toggle the metronome on and off.

## Style Guidelines:

- Primary color: Dark gray (#333333) for a professional look.
- Secondary color: Light gray (#EEEEEE) for backgrounds and subtle accents.
- Accent color: Teal (#008080) for interactive elements like the start/stop button and tempo slider.
- Clean and minimal layout with controls centered on the screen.
- Use simple, modern icons for the start/stop button.
- Subtle visual feedback (e.g., a flash or pulse) on each beat.
